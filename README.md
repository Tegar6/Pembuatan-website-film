StreamVibe 🎬

StreamVibe is a responsive, pixel-perfect film streaming web application built as part of the IMK assignment. It features a sleek dark mode UI with custom horror movie posters, category filtering, watchlist management, and an interactive video detail player.

🚀 Tech Stack

HTML5 (Semantic structure)

Tailwind CSS (via CDN for styling)

Vanilla JavaScript (SPA navigation, interactivity, state management)

✨ Features

Dynamic Navigation & SPA Routing: Seamless switching between Beranda, Explore, Daftar Simpan, and Watch & Detail pages.

Category Filtering: Filter films by genres like Horror, Komedi, Action, and Drama.

Watchlist & Save System: Add or remove movies from your personal saved list.

Interactive Modals: Share film links easily via the pop-up modal.

Responsive Design: Optimized for both desktop displays and mobile viewports.

📂 Project Structure

TugasIMK/

├── script.js        # UI logic, data state, and interactivity
└── images/          # Custom movie posters and logos


💻 How to Run Locally

Open the TugasIMK folder in VS Code.

Install the Live Server extension if you haven't already.

Right-click on index.html and select "Open with Live Server".
